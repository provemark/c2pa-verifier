# The crJSON schema

`crJSON.schema.json` is the JSON Schema (draft 2020-12, `$id`
`https://c2pa.org/crjson/crJSON.schema.json`) embedded in §5, "Full
Schema", of the C2PA 2.4 Content Credentials JSON page:
<https://spec.c2pa.org/specifications/specifications/2.4/crJSON/crjson-format.html>.

Copied on 2026-10-23 from that page's last `<pre>` block, HTML entities
decoded, nothing else changed. SHA-256:
`5d9c53ca7df9a9fe0982bd0d57d531d4badf8b91a1266f28bf1ef7154b90fc44`.

The page, and so the schema, is published by the C2PA under the Creative
Commons Attribution 4.0 International licence (CC BY 4.0). It is used here,
unchanged, to test the crJSON this verifier writes (ADR-0006, SPEC-075).
